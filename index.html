Finding 03

The Data Had A Bug — Here's What Changed

26 of 100 records have a Discharge Date before the Admission Date

Almost certainly a data-entry error, not a real event. Left unhandled, it silently breaks every stay-length and per-day-expense calculation — because a negative stay length inflates or inverts the ratio it's used in.

The "most expensive hospital per patient-day" answer flips entirely once the 26 flawed rows are excluded — a reminder that an unaudited query can point a real decision in the wrong direction.

How It Was Queried

A sample of the SQL behind these findings — all 10 assignment queries in full are in the repo.

Query — Data Quality Check
Detect invalid admission/discharge pairs
SELECT COUNT(*) AS invalid_stay_rows
FROM hospital_records
WHERE discharge_date - admission_date < 0;
-- Result: 26 rows
Query 3 — Core Assignment
Top 3 departments by patient volume
SELECT department, SUM(patients_count) AS total_patients
FROM hospital_records
GROUP BY department
ORDER BY total_patients DESC
LIMIT 3;
Query 5 — Core Assignment
Average medical expense per day, per hospital (valid stays only)
SELECT hospital_name,
       SUM(medical_expenses) / SUM(discharge_date - admission_date) AS avg_expense_per_day
FROM hospital_records
WHERE discharge_date - admission_date >= 0
GROUP BY hospital_name
ORDER BY avg_expense_per_day DESC;
